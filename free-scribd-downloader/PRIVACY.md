# الخصوصيّة

لا يحتاج التطبيق مفتاح API أو حساب GitHub أو كلمة مرور Scribd. لا يقرأ ملفات تعريف المتصفّح الشخصيّة؛ ينشئ جلسة Chrome مؤقّتة تخصّه. تصل روابط المستندات إلى مواقعها الأصليّة لتنفيذ التنزيل، وتبقى ملفات PDF في مجلّد الحفظ الذي تختاره.

لا تُرفَع ملفات PDF أو سجلّات التشغيل أو ملفات الجلسات إلى GitHub. ملفات الإصدار تُبنى من قائمة مصدر محدّدة. لا تتضمّن الحزمة مجلّد المستخدم، أو `.env`، أو `.venv`، أو ملفات Cookies، أو مفاتيح SSH، أو بيانات اعتماد.

يستخدم البناء GitHub Actions على أجهزة مستضافة، ويحمِّل الأدوات من مصادرها الرسميّة. مرجع `secrets.GITHUB_TOKEN` في سير البناء هو اسم سرّ تديره GitHub؛ لا تُكتَب قيمته في المصدر أو ملفات الإصدار. لا يتطلّب هذا الإعداد سرًّا شخصيًّا من المستخدم.

قد تتضمّن الأخطاء التقنيّة المحليّة عناوين المستندات؛ لا تشاركها علنًا قبل مراجعتها. لا توجد خدمة لرفع التشخيصات أو ملفات المستخدم تلقائيًّا. تحديث البرنامج يتمّ بتنزيل إصدار جديد واختياره يدويًّا.
