# توقيع Windows وتحذير SmartScreen

الإصدار 0.5.0 غير موقَّع رقميًّا؛ عبارة Unknown publisher ليست عطلًا يمكن إزالته بتغيير اسم الناشر في Setup. يلزم توقيع Authenticode بشهادة موثوقة أو خدمة توقيع تتحقَّق من هويّة الناشر.

هذا التعديل يجهِّز التوقيع، ولا يتضمّن شهادة أو مفتاحًا أو اشتراكًا، ولا يعني أنَّ الملف القديم أصبح موقَّعًا. لا توجد شهادة مناسبة متاحة في بيئة العمل الحاليّة. لا ترفع PFX أو المفاتيح أو كلمات المرور إلى المستودع أو المحادثة.

## مسار شهادة موجودة على جهاز التوقيع

1. أكمِل التحقُّق من هويّتك لدى جهة إصدار موثوقة، واجعل الشهادة ومفتاحها متاحَين في مخزن CurrentUser/My على جهاز التوقيع، أو عبر موفِّر HSM يدعمه Windows. لا تُصدِّر المفتاح إلى المصدر.
2. ثبِّت أدوات توقيع Windows SDK على جهاز البناء والتوقيع الموثوق.
3. عيِّن FSD_SIGN_CERT_SHA1 إلى بصمة الشهادة على ذلك الجهاز. البصمة تُحدِّد الشهادة؛ ليست المفتاح الخاص.
4. شغِّل `python build_release.py`. يوقِّع البناء التطبيق والعامل قبل ضغط الحزمة، ثم يوقِّع Setup قبل توليد SHA-256. يتوقَّف البناء إذا طُلِب التوقيع وفشل التحقُّق.
5. افحص Digital Signatures واسم الناشر في خصائص التطبيق وSetup، واختبر التثبيت على جهاز مستقل. لا تعدِّل الملفات بعد توقيعها.

أجهزة GitHub المستضافة لا تحتوي شهادتك تلقائيًّا. يلزم تكامل خدمة توقيع بهويّة متحقَّق منها، أو جهاز بناء وتوقيع موثوق. لا تُضِف قيمة البصمة وحدها إلى GitHub متوقِّعًا أنَّه يستطيع الوصول إلى المفتاح.

المسار البديل خدمة Microsoft Artifact Signing؛ يحتاج إعداد حساب وتحقُّق هويّة وتكامل خاص بالخدمة. لم يُنشَأ اشتراك ولم تُحمَّل أي تكلفة ضمن هذا التعديل.

التوقيع الموثوق يُعرِّف الناشر ويحمي سلامة الملف؛ لا يضمن اختفاء تحذير SmartScreen فورًا، ولا تعالج الشهادة الذاتيّة المشكلة للمستخدمين العامّين. لا يتضمّن التصحيح تعطيل SmartScreen أو Defender أو تثبيت جذر ثقة محلي.
