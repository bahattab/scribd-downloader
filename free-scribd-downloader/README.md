# Free Scribd Downloader

برنامج لتنزيل المستندات المتاحة لك، بواجهة عربية لسطح المكتب وواجهة ويب. يجمع روابط متعددة ويعالجها بالتسلسل، ويحفظ أسماء المستندات العربية، ويُضيف رقمًا عند تكرار الاسم لحماية الملفات الموجودة.

الإصدار البرمجي: **0.5.0**. لكل بناء منشور معرّف مستقل بصيغة `v0.5.0-build.N`.

## التنزيل والتثبيت

ملفات البناء الناجح تظهر في:
https://github.com/bahattab/scribd-downloader/releases

حالة البناء:
https://github.com/bahattab/scribd-downloader/actions/workflows/free-scribd-downloader.yml

وجود المصدر أو سير البناء لا يعني أنَّ ملفات EXE أُنتجت بنجاح؛ تحقَّق من حالة التشغيل وملفات الإصدار الفعليّة.

### Windows

شغِّل ملف `Free-Scribd-Downloader-0.5.0-Windows-Setup.exe` من إصدار ناجح. يتيح اختيار مجلّد مخصّص، ويقترح مجلّد المستخدم `AppData\Local\Programs\Free Scribd Downloader`، ويضيف اختصار قائمة البدء، واختصار سطح مكتب اختياريًّا، وأداة إزالة التثبيت. لا يتطلّب صلاحيات مسؤول.

الحزمة مُعدَّة لتضمين Python وNode.js وSelenium وpypdf وChrome for Testing وChromeDriver المطابق؛ لا تحتاج تثبيتها يدويًّا بعد اكتمال بناء الحزمة. احتفظ بجميع ملفات النسخة المحمولة معًا، أو استخدم Setup لتجميعها في مجلّد واحد. لا تنسخ EXE وحده بعيدًا عن مجلّداته.

### Linux وmacOS

يتولّى سير البناء إنشاء حزمة منفصلة على كل نظام. فكّ ملف tar.gz في مجلّدك وشغِّل `FreeScribdDownloader`. نسخة Windows لا تعمل مباشرةً على هذين النظامَين. يحتاج Linux بيئة سطح مكتب ومكتبات نظام تدعم Tk وChrome؛ راجع رسائل اختبار البناء على التوزيعة المستهدفة. حزم macOS غير موقَّعة أو موثَّقة لدى Apple حاليًّا؛ لا يُدَّعى اعتمادها للتوزيع العامّ.

المستهدف: Windows x64، وLinux x64، ومعمارية جهاز macOS الذي يبني عليه GitHub Actions. لا يشمل هذا الإصدار الهواتف أو جميع أنظمة التشغيل والتوزيعات والمعماريّات.

## الاستخدام

1. افتح Free Scribd Downloader.
2. ألصق حتى 20 رابطًا، كل رابط في سطر مستقل.
3. أكِّد حقَّ تنزيل المستندات، واختر مجلّد الحفظ.
4. اضغط «بدء التنزيل». تُعالَج الملفات واحدًا تلو الآخر؛ تعذُّر أحدها لا يمنع متابعة الباقي.
5. تعني «حُفظ في المجلّد» اكتمال كتابة PDF فعليًّا. زر الإلغاء يُوقِف الملفات المتبقّية، مع الإبقاء على الملفات المحفوظة.

الأسماء تُؤخَذ من عنوان المصدر متى أتاحه، ثم من عنوان الرابط؛ قد يُستخدَم اسم بديل عند غياب العنوانين. لا يضمن البرنامج إتاحة كل مستند، ولا يتجاوز طلبات الدخول أو التحدّيات البشريّة.

## الحدود

- قائمة بحدّ 20 رابطًا؛ عامل معالجة واحد.
- 20 ميغابايت و300 صفحة للملف؛ خمس دقائق للمعالجة.
- التخزين المؤقّت: حتى 400 ميغابايت و40 ملفًّا.
- تتطلّب الروابط اتصالًا بالإنترنت. لا تُحفَظ القوائم بعد إعادة تشغيل المحرِّك.
- استخدم البرنامج للمستندات التي تملك حقَّ الوصول إليها وتنزيلها.

## نسخة الويب

المصدر في `free-scribd-downloader/`. لتشغيله محليًّا ثبِّت Python 3.10+ وNode.js 24 وChrome، ثم شغِّل `Setup-Windows.cmd` و`Start-Windows.cmd`، أو `python -m pip install -r requirements.txt` ثم `node server.mjs` على الأنظمة الأخرى. عنوان التشغيل المحلي http://127.0.0.1:3080 . للنشر العامّ، راجع WEB-DEPLOY.md لإعداد HTTPS والدخول الخاص؛ لا توجد استضافة عامة منشأة تلقائيًّا.

## البناء والاختبارات

من مجلّد `free-scribd-downloader`:

```text
python -m pip install -r build/requirements.txt
node --test
python -m unittest discover -s test -p test_*.py
python build_release.py
```

على Windows يلزم Inno Setup 6 للبناء فقط. ينتج البناء مجلّد `dist/FreeScribdDownloader` وملفات `release/`. يُفحَص المحرِّك المضمَّن، وحفظ PDF نموذجي، واعتماديات العامل، وتشغيل Chrome المضمَّن وطباعة صفحة محليّة. يفحص سير Windows تثبيت Setup وتشغيل التطبيق المثبَّت وإزالته. هذه الفحوص لا تثبت نجاح تنزيل كل مستند Scribd حيّ.

لا يُنشر الإصدار تلقائيًّا إلا إذا نجحت وظائف بناء الأنظمة الثلاثة وفحوصها. تتضمّن الإصدارات بصمات SHA-256. لا توجد شهادة توقيع رقمي لملفات Windows حاليًّا.
